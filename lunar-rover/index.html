EXPLORATION ALGORITHM SPECIFICATION

Robotic motion planning, mathematical optimization & energy budgeting

1. Budget-Constrained Frontier Exploration (BCFE)

Industry Standard

Frontier exploration (first formalized by Brian Yamauchi) detects boundaries between known free space and unknown unexplored territory. In space robotics (such as NASA VIPER, ESA Rosalind Franklin, or lunar rovers), the classic formulation suffers from fatal battery stranding because it does not model the energy cost of returning to a power station.

Mathematical Formulation
f* = arg maxf ∈ Ffeasible [ w1 · I(f) - w2 · Drover(f) ]
Subject to the Feasibility Constraint:
Drover(f) + α · Dbase(f) ≤ Batterycurrent
Why the Safety Factor (α > 1.0)?

Lunar regolith induces wheel slippage (slip ratios up to 20-30%). Newly revealed obstacles can block the originally estimated return corridor. Setting α = 1.35 ensures the rover reserves 35% surplus energy to handle detours.

Guaranteed Invariant

As long as the rover's known map preserves a connected path to base, the rover will never be stranded, achieving 0% failure rates across arbitrary terrain topologies.

Algorithmic Pseudocode 
function SelectBudgetedGoal(frontiers, rover, base, alpha):
    bestGoal ← null
    maxUtility ← -∞

    for each f in frontiers:
        pathOut ← AStar(rover.pos, f.pos, allowUnexplored=true)
        if pathOut is null: continue

        pathHome ← AStar(f.pos, base.pos, allowUnexplored=false)
        if pathHome is null: continue

        budgetRequired = length(pathOut) + (alpha * length(pathHome))
        if budgetRequired ≤ rover.battery:
            infoGain = EstimateUnmappedNeighbors(f.pos)
            utility = (infoGain * 1.5) - (length(pathOut) * 1.0)
            if utility > maxUtility:
                maxUtility = utility
                bestGoal = f

    return bestGoal // If null, initiate immediate Safe-Home-Return

2. Next-Best-View (NBV) Utility Maximization

Adaptive Information Gain

Next-Best-View (NBV) treats exploration as an active perception problem. Instead of simply reaching boundaries, it calculates the solid angle or volume of unmapped terrain uncovered per unit of energy expended, balancing scientific discovery against risk.

Utility Function with Exponential Risk Decay
U(f) = [ I(f) / (Drover(f) + 1) ] − λ · exp( - [Battery - Costtotal(f)] / τ )

When battery surplus is high, the exponential penalty is negligible, allowing the agent to target high-yield frontiers. When surplus drops towards zero, the penalty term explodes, naturally forcing the rover to abort outward exploration and prioritize return paths.

Advantages

Prioritizes open expanses with immense sensor coverage rather than narrow corridors with low information yield.

Tuning Sensitivity

Requires calibrating τ and λ. An aggressive setting may push the rover slightly deeper than safe bounds if a very high-gain view is detected nearby.

3. Yamauchi Greedy Frontier Search

Historical Baseline

Introduced by Brian Yamauchi in 1997 ("A Frontier-Based Approach for Autonomous Exploration"), this algorithm seeks to minimize travel distance by always steering the robot toward the geometrically nearest frontier cell.

Decision Formulation
f* = arg minf ∈ F [ Drover(f) ]

The Fatal Planetary Flaw: It contains zero advance awareness of the base location during target selection. The rover happily ventures deep into distant craters, only checking battery when already at the critical margin. If a newly discovered obstacle blocks the direct way back, the rover becomes stranded.

4. Random Walk Baseline

Null Hypothesis

A stochastic reactive controller similar to simple robotic vacuum cleaners. The rover picks random valid trajectories among reachable frontiers, demonstrating what happens without frontier clustering, graph utility optimization, or path planning.

Used in robotics literature as a control experiment to quantify the exact efficiency gains of deliberate SLAM and utility-directed navigation.
